# Thesis-BBH-U-talent
Repository voor thesisproject
  
## Vereisten
### 1. Python 3.12
Oudere versies zijn niet getest, nieuwere versies werken niet.
### 2. Een Linux besturingssysteem of emulator
Kan ook zonder maar dan wordt het installeren van pycbc een stuk lastiger.
### 3. 8+ GB RAM-geheugen
Meer wordt aanbevolen. Het programma maakt namelijk gebruik van een groot aantal Templatewave class-instances.
  
## Hoe te gebruiken
Het programma kan gebruikt worden door het project te downloaden en *src/main.py* te runnen. Het is wel noodzakelijk dat er een templatbank-bestand 'templatebank.pickle' in de projectmap zit. Deze is te groot voor Github, maar kan gegenereerd worden door *src/templatebankgenerator.py* te runnen. Dit maakt een bestand van ~4GB en duurt ~10 uur.
